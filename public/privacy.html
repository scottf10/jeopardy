Classroom Jeopardy

Privacy

Teams enter a team name and use a temporary game-session token. The game stores team scores, Final Jeopardy wagers and responses, and session activity so the teacher can run the game. Team devices do not use Google sign-in.

Teachers sign in with Google. Only approved teacher accounts can create question sets, run sessions, and review team responses. Data is stored in Supabase and the site is hosted by Cloudflare.
